## VortexPass v0.0.9 — PathFix

- Исправлена загрузка картинок Roblox: для проблемных DNS-ответов добавлен прямой резерв Quad9 UDP/TCP и обработка цепочек CDN. WARP для Roblox не используется.
- Добавлена отдельная проверка аватарок и миниатюр игр; ответы API без изображения не считаются подтверждением контента.
- Исправлена выдача браузерного PAC для Telegram Web и дополнен список адресов Telegram.
- Проверки YouTube отдельно учитывают аватарки каналов; работающие профили сохраняются.
- Техническая версия приложения, установщика обновлений и DNS-компонента — 0.0.9. Проверены обнаружение обновления с 0.0.8 и обнаружение следующей тестовой версии из 0.0.9.

Скачайте **VortexPass-win-x64.zip** и сверяйте его SHA-256 с **VortexPass-win-x64.zip.sha256**. Для ручного обновления остановите подключение и полностью закройте прежнюю программу через трей, затем распакуйте новый комплект в постоянную папку. Пользовательские профили хранятся отдельно. Встроенное обновление также доступно из приложения.

Исправление Roblox подтверждено пользователем на проблемной сети: картинки загружаются. Универсальная загрузка моделей во всех играх не заявляется; для конкретной игры доступна диагностика Roblox Player. В комплект включены локальная модель и официальный установщик WARP; его условия принимает пользователь. Обычный логотип и описание проекта сохранены в README.
