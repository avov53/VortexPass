VortexPass · Halloween — отдельный дизайн-прототип

Откройте standalone.html двойным щелчком. Интернет и запуск приложения не нужны.
Для разработки из этой папки: npm run dev (http://127.0.0.1:5175).
Сборка: npm run build. Используются зависимости родительской папки design/node_modules.

Исходники скопированы из design/src. Основной дизайн и приложение не изменены.
Хранилище профилей изолировано: vortexpass.halloween.profiles.v2.
Все подключения, WARP и подбор параметров демонстрационные.
Профили изначально пустые; можно создать свой через вкладку «Профили».
Светлая версия доступна в настройках внешнего вида. Анимация учитывает уменьшение движения.
