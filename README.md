# VortexPass

WPF/.NET 8 x64 launcher for Windows 10/11 with a GitHub Releases updater.

В приложении доступны независимые профили YouTube, Discord, Telegram, Web и Game Filter, пять уровней ускарения, автоматический подбор подходящего уровня по сетевой диагностике, управление защитой из системного трея и безопасное восстановление изменённых сетевых параметров.

Приложение запрашивает права администратора при запуске. Внешние компоненты проверяются по SHA-256 до запуска; при несовпадении VortexPass не запускает сетевые процессы и показывает точную причину в журнале.
