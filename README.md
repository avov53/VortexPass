# VortexPass

VortexPass - аккуратный сетевой ускоритель для Windows 10/11. Он помогает подобрать стабильный профиль соединения для популярных веб-сервисов, голосовой связи, Telegram Desktop и отдельных игр, а также может управлять установленным официальным клиентом Cloudflare WARP.

![VortexPass logo](src/VortexPass.App/Assets/VortexPass-logo.png)

## Что умеет VortexPass

- **Профили под разные сценарии:** YouTube, Discord, Telegram, Web и Game Filter.
- **5 уровней сетевой настройки:** от мягкого режима до более активного профиля для сложных соединений.
- **Индивидуальный автоподбор:** локальная модель помогает подобрать параметры под сеть пользователя, а приложение проверяет результат. Обычный поиск — до 180 секунд, расширенный — до 6 минут. Для YouTube доступен отдельный подбор с сохранением настроек остальных сервисов.
- **Game Filter:** отдельные настройки для игр, где важны стабильная сессия, низкие потери и предсказуемое соединение.
- **Telegram Desktop:** локальный `TG WS Proxy` для Telegram Desktop без стороннего прокси-сервера.
- **Cloudflare WARP:** подготовка официального клиента и выборочное подключение Telegram Web; область действия показана в интерфейсе.
- **Управление из трея:** быстрое включение, выключение и возврат окна.
- **Безопасное восстановление:** при остановке VortexPass возвращает изменённые сетевые параметры в исходное состояние.
- **Проверка компонентов:** внешние файлы проверяются по SHA-256 до запуска.
- **Обновления через GitHub Releases:** приложение проверяет новые версии и скачивает только ZIP-пакет с контрольной суммой.

## Скачать

Текущий выпуск — **v0.0.9**. Последняя версия публикуется в разделе [Releases](https://github.com/avov53/VortexPass/releases).

Скачивайте файл:

```text
VortexPass-win-x64.zip
```

Рядом с ним должен быть файл контрольной суммы:

```text
VortexPass-win-x64.zip.sha256
```

## Установка

1. Скачайте `VortexPass-win-x64.zip` из последнего релиза.
2. Распакуйте архив в удобную папку, например `C:\Tools\VortexPass`.
3. Запустите `VortexPass.exe`.
4. Подтвердите запрос Windows на права администратора.
5. Подготовьте WARP, приняв условия Cloudflare, если клиент ещё не установлен и не зарегистрирован.
6. Создайте профиль, выберите сервисы, выполните автоподбор и подключите выбранный вариант.

Основная программа запускается из распакованной папки. В комплект входят необходимые компоненты, локальная модель и официальный установщик WARP. WARP устанавливается как служба Windows, поэтому эта часть требует установки и не является полностью portable. Для удаления сначала отключите профиль и автозапуск, закройте приложение и удалите его папку. Клиент WARP при необходимости удаляется отдельно средствами Windows.

## Зачем нужны права администратора

VortexPass управляет локальными сетевыми компонентами Windows, системным прокси, DNS/hosts-настройками и драйвером WinDivert. Эти действия требуют прав администратора, поэтому приложение запрашивает их при каждом запуске.

## Безопасность

Основные профили работают локально и не направляют трафик через сервер разработчика. Для выбранных сервисов может использоваться официальный Cloudflare WARP. Его область действия зависит от настроек профиля.

Перед запуском сетевых компонентов приложение проверяет закреплённые файлы по SHA-256. Если файл изменён, повреждён или не совпадает с ожидаемой контрольной суммой, VortexPass не запускает сетевой процесс и показывает причину в журнале.

В проекте используются внешние компоненты:

- `winws`, `WinDivert` и сопутствующие списки из набора Flowseal.
- `TgWsProxyHeadless` для локального Telegram Desktop WS Proxy.
- Официальный Cloudflare WARP, подготовленный при первом запуске или на странице WARP после принятия условий Cloudflare.

Исходники и лицензии закреплённых компонентов указаны в:

- `components/zapret/SOURCE.txt`
- `components/zapret/FLOWSEAL-LICENSE.txt`
- `components/zapret/TG-WS-PROXY-LICENSE.txt`

## Как пользоваться

1. Откройте VortexPass.
2. Создайте сохранённый профиль и выберите нужные сервисы: YouTube, Discord, Telegram, Web или Game Filter.
3. Если не знаете, какой уровень выбрать, запустите автоподбор.
4. Для игр откройте Game Filter и отметьте нужную игру.
5. Запустите защиту.
6. Когда VortexPass больше не нужен, выключите защиту в окне приложения или через трей.

## Профили

| Профиль | Для чего |
| --- | --- |
| YouTube | Более стабильная загрузка видео и веб-ресурсов YouTube |
| Discord | Стабилизация веб-клиента, голосовой связи и медиа-соединений Discord |
| Telegram | Локальный прокси для Desktop и выборочный WARP для Web |
| Web | Общий профиль для популярных веб-сценариев |
| Game Filter | Точечные настройки для игр, где важна стабильность сессии |

## Cloudflare WARP

При первом запуске VortexPass предлагает принять условия Cloudflare и подготовить официальный клиент, если он ещё не установлен и не зарегистрирован. Без принятия условий можно выйти из приложения. Уже подготовленный клиент используется повторно; пользовательский аккаунт Cloudflare не нужен.

Telegram Web может работать через выборочный WARP: только выбранные сайты направляются через локальный прокси. Для Firefox необходимо использование системных настроек прокси. На странице WARP рядом с подключением указана область действия: «Выбранные сайты» или «Весь компьютер». Если маршрутом управляет активный профиль, отключайте его через профиль.

Установка проверяется по закреплённой контрольной сумме и цифровой подписи Cloudflare. Отдельное окно Cloudflare для обычной работы не требуется. Подробности соединения и очищенный отчёт доступны в диагностике.

## Автозапуск и оформление

В настройках можно включить запуск VortexPass при входе в Windows и отдельно выбрать сохранённый профиль для автоматического подключения. Переименование профиля не сбрасывает этот выбор. Приложение запускается в трее и использует сохранённые параметры без нового ИИ-подбора.

В v0.0.8 доступно хеллоуинское оформление. Обычный стиль сохранён: вернуться к нему можно в настройках внешнего вида. Обычный логотип проекта остаётся в этом README.

## Обновления

VortexPass проверяет обновления в репозитории `avov53/VortexPass`.

Релиз должен содержать два файла:

- `VortexPass-win-x64.zip`
- `VortexPass-win-x64.zip.sha256`

ZIP-пакет скачивается во временную папку, проверяется по SHA-256 и только после этого применяется. Если контрольная сумма не совпала, обновление отменяется. При замене файлов создаются резервные копии для восстановления при ошибке. В v0.0.8 проверены обнаружение нового выпуска и установка следующей версии на изолированном тестовом комплекте.

## Сборка из исходников

Требования:

- Windows 10/11 x64
- .NET 8 SDK
- Node.js и pnpm для сборки веб-интерфейса

Установите frontend-зависимости командой `pnpm install --frozen-lockfile` в `src/VortexPass.App/web-src`. Затем выполните `scripts/Prepare-LocalAiBundle.ps1`, `scripts/Prepare-WarpInstaller.ps1`, `scripts/Prepare-TelegramRuntime.ps1` и `build-release.ps1`. Версия задаётся в `VERSION` и должна совпадать с версией frontend package.json. Загружаемые компоненты проверяются по закреплённым хешам; Telegram runtime восстанавливается из опубликованного v0.0.8. Личные настройки, профили и журналы в исходники не включены.


## Частые вопросы

### Это вирус?

Нет. VortexPass - это открытый Windows-лаунчер с локальными сетевыми компонентами. Он запрашивает права администратора, потому что работает с сетевыми настройками Windows и драйвером WinDivert. Из-за этого некоторые антивирусы могут показывать предупреждение для неизвестного или неподписанного приложения. Код и список внешних компонентов доступны в репозитории.

### Почему Windows показывает предупреждение SmartScreen?

Обычно SmartScreen предупреждает о новых приложениях без платной цифровой подписи и большой истории загрузок. Это не означает, что файл вредоносный, но пользователю всё равно стоит скачивать VortexPass только из официальных Releases и сверять контрольную сумму.

### Что это за программа простыми словами?

Это приложение для настройки и стабилизации сетевых соединений на Windows. Вы выбираете нужный сценарий, а VortexPass запускает локальные компоненты и применяет подходящий профиль.

### Это VPN?

Основные сетевые профили работают локально. Дополнительно приложение использует официальный Cloudflare WARP для выбранных сайтов либо всего компьютера, в зависимости от настроек. Область действия указана в интерфейсе.

### Программа собирает мои данные?

VortexPass не требует аккаунта и не отправляет личные данные разработчику. Журналы нужны для диагностики работы на вашем компьютере.

### Почему нужен WinDivert?

WinDivert используется для локальной обработки отдельных сетевых соединений в Windows. Без него часть профилей не сможет работать корректно.

### Что делать, если после выключения что-то работает не так?

Сначала выключите защиту в VortexPass и закройте приложение. При штатной остановке оно восстанавливает изменённые параметры. Если проблема осталась, перезагрузите Windows и проверьте системный прокси в настройках сети.

### Можно ли удалить программу?

Да. Выключите защиту, закройте VortexPass и удалите папку с приложением. Если включали автозапуск, сначала отключите его в настройках приложения.

### Почему Telegram Desktop просит подтвердить прокси?

Для Telegram Desktop используется локальный прокси `127.0.0.1:1443`. Это компонент на вашем компьютере, а не сторонний сервер. Telegram может попросить подтвердить подключение к нему.

### Какие игры поддерживает Game Filter?

В текущей версии профиль рассчитан на Roblox и Phasmophobia. Для других игр лучше использовать общий Web-профиль только если он действительно помогает вашему соединению.

## Лицензии и благодарности

VortexPass использует сторонние компоненты, которые распространяются на условиях их собственных лицензий.
