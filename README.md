# VortexPass

Локальное приложение для Windows x64: профили обхода DPI, индивидуальный подбор YouTube и выборочный WARP для Telegram Web. Telegram Desktop использует tg-ws-proxy. Работоспособность зависит от сети и проверяется на компьютере пользователя.

## Установка v0.0.8

Скачайте `VortexPass-win-x64.zip` и файл `.sha256` из [GitHub Releases](https://github.com/avov53/VortexPass/releases), проверьте SHA-256 и распакуйте в постоянную папку. Запустите `VortexPass.exe` с правами администратора. В комплект входят .NET runtime, локальная модель и официальный установщик WARP.

При отсутствии подготовленного WARP необходимо самостоятельно принять условия Cloudflare и выполнить подготовку либо выйти. Установку и системный запрос прав программа не обходит. Пользовательский аккаунт Cloudflare не требуется. WARP устанавливается как служба Windows, поэтому эта часть не является полностью portable.

Создайте профиль, выполните подбор, выберите измеренный вариант и подключите его. Для работающего профиля доступен отдельный подбор только YouTube. Обычный поиск ограничен 180 секундами, расширенный — шестью минутами. Успешная проверка страницы не означает подтверждение видео или личных вложений.

## Автозапуск и оформление

Настройки → Общие: включите запуск с Windows и выберите профиль автоподключения. Выбор сохраняет профиль и включает автоподключение. В журнале видны причины запуска или пропуска. Автозапуск происходит при входе пользователя, с ограниченными повторными попытками.

Хеллоуинское оформление включено по умолчанию. Настройки → Внешний вид → Сезонное оформление → Обычное возвращает прежний интерфейс и значки окна/трея. Для EXE с обычной иконкой собирайте с `-p:SeasonalBuild=false`.

## Обновления

Приложение проверяет опубликованный стабильный релиз в этом репозитории. Релиз должен содержать ровно именованные `VortexPass-win-x64.zip` и `VortexPass-win-x64.zip.sha256`. Версия тега должна быть новее установленной. ZIP скачивается и проверяется по SHA-256; при ошибке проверки установка не запускается. Установщик создаёт резервные копии заменяемых файлов и пытается восстановить их при ошибке.

Версия всех .NET-компонентов берётся из корневого файла `VERSION`. Для следующего выпуска измените VERSION и версию frontend package.json согласованно. Не публикуйте тестовый v0.0.9: проверка перехода выполняется локально с подставным HTTP и изолированными файлами.

## Сборка исходников

Требуются Windows, .NET SDK 8 и Node.js с pnpm. Зависимости frontend устанавливаются в `src/VortexPass.App/web-src` командой `pnpm install --frozen-lockfile`. Затем запустите `scripts/Prepare-LocalAiBundle.ps1`, `scripts/Prepare-WarpInstaller.ps1`, `scripts/Prepare-TelegramRuntime.ps1` и `build-release.ps1`. Загрузки идут из закреплённых официальных источников с проверкой хешей; при изменении установщика WARP сборка останавливается до пересмотра закреплённой версии и transform.

Исходники сторонних компонентов, версии и лицензии указаны в `components/zapret/SOURCE.txt`, файлах LICENSE и манифестах. Бинарники локальной модели, Telegram runtime и WARP MSI не хранятся в main; они входят в релизный ZIP. Telegram runtime восстанавливается из опубликованного v0.0.8 с проверкой закреплённого манифеста и каждого файла. До публикации релиза сборщику нужна локальная копия runtime или ZIP; альтернативная пересборка кандидата из официальных исходников описана в scripts/Build-TelegramProxy.ps1 и требует пересмотра хешей. Публичные исходники не включают личные настройки, профили, журналы, ключи, рабочие резервные копии и каталоги dist/artifacts.

## Проверка перед выпуском

Запустите Core и WPF/Tray тесты, сборку TypeScript и интеграционную проверку обновления. На целевой Windows отдельно проверьте вход в систему, отмену автоподключения и реальные сервисы: YouTube с перемоткой, Telegram Web, звонок и Discord. Автоматические проверки не заменяют испытание проблемной сети.
