# VortexPass


WPF/.NET 8 x64 launcher for Windows 10/11 with a GitHub Releases updater.

В приложении доступны независимые профили YouTube, Discord, Telegram, Web и Game Filter, пять понятных уровней ускарения, автоматическая проверка 20 внутренних стратегий, управление защитой из системного трея и безопасное восстановление изменённых сетевых параметров.

Приложение запрашивает права администратора при запуске. Внешние компоненты проверяются по SHA-256 до запуска; при несовпадении VortexPass не запускает сетевые процессы и показывает точную причину в журнале.

Для Telegram Desktop используется локальный `TG WS Proxy` от Flowseal: MTProto-трафик остаётся зашифрованным Telegram и передаётся через WebSocket/TLS без стороннего прокси-сервера. Исходники и лицензии закреплённых компонентов указаны в `components/zapret/SOURCE.txt`, `FLOWSEAL-LICENSE.txt` и `TG-WS-PROXY-LICENSE.txt`.
